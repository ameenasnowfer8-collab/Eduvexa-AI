# Eduvexa AI

## An AI-Powered Student Assistant using Hugging Face and Streamlit

Eduvexa AI is an AI-powered student assistant designed to help students
with learning, programming, mathematics, artificial intelligence,
projects, and general academic questions.

The application uses a Hugging Face Transformer model and Streamlit
to provide a simple, interactive, and user-friendly AI interface for students.

## Features

- Ask questions using natural language
- AI-generated responses
- Study assistance
- Python programming help
- Mathematics and factorial questions
- Artificial Intelligence concepts
- Project-related assistance
- Student-focused learning support
- Simple and interactive Streamlit interface

## AI Model

The project uses the following Hugging Face model:

**SmolLM2-360M-Instruct**

Model:

`HuggingFaceTB/SmolLM2-360M-Instruct`

The model is used through the Hugging Face Transformers
`text-generation` pipeline to generate responses to student questions.
